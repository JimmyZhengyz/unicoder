# Evaluation

This directory contains the current public evaluation release for UniCoder.

## Structure

- `simple_eval/`: Unified wrapper for running ChartMimic and UniSVG evaluations.
- `ChartMimic/`: Adapted ChartMimic evaluation resources.
- `unisvg.github.io/`: Adapted UniSVG evaluation resources.

Please see the root `README.md` for installation, data preparation, and quick-start commands.
